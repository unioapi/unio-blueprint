# Documentation Site（文档站）领域决策

## 目的

记录影响范围完全位于文档站领域内的长期选择。

## 范围

文档站产品架构、信息架构、内容交付、内容发现和领域内部技术约束。

## 职责

- 保存决策背景、备选方案与影响。
- 链接受影响的页面设计、质量目标和路线图事项。
- 将跨领域选择提升为全局决策。

## 适合存放的内容

- 文档站领域已提议、接受、取代或拒绝的 ADR。
- 不会对其他产品领域施加规则的决策。

## 不应存放的内容

- 平台级选择、临时笔记或实现任务。
- 由其他产品领域负责的决策。

当前尚未记录文档站领域决策。新建时使用 [ADR 模板](../../templates/adr.md)。
