# Documentation Site（文档站）页面设计

## 目的

定义文档站页面和跨页面旅程的目标、内容、状态与交互。

## 范围

文档站自有页面设计、与具体路由无关的旅程、内容要求和验收标准。

## 职责

- 为每个页面或旅程建立唯一权威设计。
- 将共享模式链接到平台规范。
- 覆盖响应式、无障碍、加载、空状态和错误状态。

## 适合存放的内容

- 使用[页面设计模板](../../templates/page-design.md)创建的文档站页面设计。
- 文档站用户旅程图和页面级内容模型。

## 不应存放的内容

- 生成的参考内容、组件源码、框架路由、共享 UI 规范或其他领域负责的页面。
