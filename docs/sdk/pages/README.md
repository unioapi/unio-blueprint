# SDK（软件开发工具包）页面设计

## 目的

当 SDK 明确拥有面向用户的页面或多步骤交互旅程时，为其提供权威位置。

## 范围

只包含产品所有权属于 SDK，而不属于 Documentation Site、Console、Admin 或
Website 的用户界面。

## 职责

- 新建页面设计前确认所有权确实属于 SDK。
- 将共享模式链接到平台规范。
- 覆盖无障碍、加载、空状态和错误状态。

## 适合存放的内容

- 使用[页面设计模板](../../templates/page-design.md)创建的 SDK 自有页面设计。

## 不应存放的内容

- 生成的参考页面、语言包文档、实现路由或其他产品领域负责的页面。
