# 图标规范

## 目的

确保图标在所有 UnioAPI 界面中表达稳定含义并保持可用。

## 待定义标准

- 允许使用的图标来源与补充流程
- 语义映射和禁止出现的歧义
- 尺寸、线条、对齐与视觉修正
- 无障碍名称、提示和装饰性图标
- 仅图标按钮的使用条件
- 产品专用与共享资源的所有权
