# 权限规范

## 目的

统一 UnioAPI 各产品中权限概念的命名、判断、对外表达与解释方式。

## 待定义标准

- 主体、角色、资源、操作与作用域
- 默认拒绝与最小权限原则
- 服务端强制校验和客户端展示
- 权限标识符与兼容性
- 拒绝、隐藏、禁用和申请权限状态
- 审计、委托与生命周期

## 边界

本文定义公共权限模型。领域专用权限清单和业务流程留在对应产品领域。
