# 颜色规范

## 目的

定义能够跨产品和主题保持一致的语义颜色角色。

## 待定义标准

- 表面、文字、边框、操作和状态的语义角色
- 颜色变量命名与继承
- 亮色、暗色和高对比度主题
- 对比度与非颜色信息表达
- 数据可视化色板和冲突规则
- 颜色变量的弃用与迁移

## 边界

本文负责颜色含义和无障碍要求，不负责产品专用品牌素材或框架配置。
