# 字体排版规范

## 目的

定义界面与发布内容使用的语义字体角色和可读性约束。

## 待定义标准

- 字体家族与回退方案
- 展示、标题、正文、标签、代码和数据角色
- 字号、字重、行高与换行约束
- 不依赖视口缩放字体的响应式层级
- 国际化与字符覆盖
- 加载、渲染与无障碍要求

## 边界

页面专用层级属于页面设计；实现变量只能引用本文定义的语义角色，不能重新定义。
