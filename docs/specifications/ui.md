# 用户界面规范

## 目的

定义跨产品交互规则，使 UnioAPI 界面保持一致、无障碍且高效。

## 待定义标准

- 布局、密度、层级与响应式行为
- 焦点、选择、反馈、加载、空状态与错误状态
- 命令、危险操作、确认与恢复
- 无障碍基线和支持的输入方式
- 可复用组件行为与组合规则
- 内容语气和本地化约束

## 权威边界

本文负责共享行为。视觉变量由[颜色](colors.md)和[字体排版](typography.md)负责；
专用控件由[表单](forms.md)和[表格](tables.md)负责。
