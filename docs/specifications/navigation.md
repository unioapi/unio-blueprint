# 导航规范

## 目的

定义共享导航概念，使用户能够在 UnioAPI 各产品内外稳定、可预测地移动。

## 待定义标准

- 全局、局部、上下文和工具导航的职责
- 标签、顺序、分组与当前状态
- 响应式布局和键盘导航
- 面包屑、深链接、重定向与上下文保留
- 空、不可用和无权限目标的表现
- 跨产品跳转和身份连续性

## 边界

本文负责可复用导航行为。某个产品的网站地图、路由和页面层级属于该领域的
`pages/` 目录。
