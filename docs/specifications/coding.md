# 编码规范

## 目的

定义不受语言和产品限制、所有实现仓库都应遵守的工程要求。

## 待定义标准

- 正确性、可读性与变更范围要求
- 与风险相匹配的测试层级和证据
- 依赖评估与生命周期
- 安全、隐私与密钥处理
- 兼容性、迁移与回滚
- 错误处理、可观测性与运营准备
- 生成代码和产物所有权

## 边界

语言格式、构建命令、目录布局和框架指南属于各代码仓库。本文只保留跨仓库基线。
