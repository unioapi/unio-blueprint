# Specifications（平台规范）

## 目的

当一致性属于平台要求时，明确 UnioAPI 各产品应如何设计与建设。

## 范围

语言、API、导航、权限、界面、设计变量、组件、可观测性和工程实践等跨产品规则。

## 职责

- 将已经接受的平台意图转化为清晰、可验证的标准。
- 为每项规则说明适用范围、负责人、例外条件和落地路径。
- 保持共享行为一致，同时不侵入具体产品功能设计。
- 将规范链接到支撑它的决策和质量属性。

## 适合存放的内容

- 适用于两个或更多产品领域的规则。
- 共享词汇、交互模式和兼容性契约。
- 明确的一致性要求与例外条件。

## 不应存放的内容

- 只有架构依据、但没有强制规则的内容。
- 单一产品的页面、流程或实现计划。
- 框架教程或某个仓库专用的检查配置。
