# 表单规范

## 目的

统一用户输入、校验、检查、提交数据以及从错误中恢复的方式。

## 待定义标准

- 标签、说明、必填标记与默认值
- 控件选择与键盘行为
- 客户端和服务端校验时机
- 字段、表单和传输错误
- 未保存状态、取消、确认与恢复
- 加载、成功、重试与防重复提交
- 无障碍和敏感数据处理

## 边界

本文负责可复用表单行为。字段定义和业务校验属于对应产品或 API 设计。
