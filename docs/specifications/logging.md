# 日志规范

## 目的

定义共享日志契约，支持跨产品诊断、关联、审计与安全运营。

## 待定义标准

- 事件分类、严重级别和必填字段
- 关联、链路、操作主体与资源标识符
- 敏感数据分类与脱敏
- 错误表达和堆栈处理
- 审计事件边界与不可变性
- 采样、保留、访问与删除
- 一致性验证与证据

## 边界

供应商配置、仪表盘查询和产品运行手册属于对应实现的运营资料。
