# 表格规范

## 目的

统一结构化数据的浏览、比较、选择与操作方式。

## 待定义标准

- 列命名、对齐、宽度、截断与密度
- 排序、筛选、分页与保存视图
- 选择、批量操作、行操作与导航
- 加载、空、部分、过期与错误状态
- 响应式行为与无障碍要求
- 日期、数字、标识符、状态和敏感数据的展示

## 边界

本文负责可复用表格行为。具体页面的数据集、列、操作和业务规则由页面设计负责。
