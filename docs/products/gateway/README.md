# Gateway（网关）

## 目的

集中维护网关的产品方向、契约设计、质量要求、路线图和领域决策。

## 范围

API 流量处理、兼容性行为、路由职责、网关自有契约和领域专用运营概念。

## 职责

- 定义网关使用者、目标和边界。
- 维护网关自有行为与契约的权威说明。
- 记录只影响网关的决策和质量目标。
- 遵循并推动共享 API 规范演进。

## 适合存放的内容

- 网关概览、路线图、词汇表和质量目标。
- 产品层面的网关功能与契约设计。
- 仅由网关使用的决策、图示和资源。

## 不应存放的内容

- 共享 API 规范或平台架构。
- 源代码、处理器清单、代码生成 Schema 或运行手册。
- 使用网关数据的 Console 或 Admin 流程。
