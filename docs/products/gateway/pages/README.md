# Gateway（网关）页面设计

## 目的

当网关明确拥有面向用户的页面或多步骤旅程时，为其提供权威位置。

## 范围

只包含产品所有权属于网关，而不属于 Console、Admin、Website 或 Documentation Site
的用户界面。

## 职责

- 新建页面设计前确认所有权确实属于网关。
- 将共享模式链接到平台规范。
- 覆盖无障碍、权限、加载、空状态和错误状态。

## 适合存放的内容

- 使用[页面设计模板](../../../templates/page-design.md)创建的网关自有页面设计。

## 不应存放的内容

- API 契约、生成的参考页面、实现路由或其他产品领域负责的页面。
