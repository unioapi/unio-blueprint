# Gateway（网关）图示

## 目的

存放仅由网关文档使用的图示源文件和可读版本。

## 范围

网关流程、契约关系、领域边界和领域架构图。

## 职责

- 同时保留可编辑源文件和可读版本。
- 每张图都必须由说明性 Markdown 文档引用。
- 提供无障碍文字说明和明确负责人。

## 适合存放的内容

- 网关专用 Mermaid、Excalidraw 或图片图示。

## 不应存放的内容

- 共享平台图、环境拓扑、没有说明的导出文件或生成的运营内容。
