# Admin（管理后台）资源

## 目的

存放仅由管理后台领域使用的权威视觉资源。

## 范围

管理后台专用图片、媒体和可编辑视觉源文件。

## 职责

- 记录来源、所有权、授权方式和用途。
- 使用描述性的小写 kebab-case 文件名。
- 后续维护需要时保留可编辑源文件。

## 适合存放的内容

- 已批准并由管理后台领域文档引用的专用视觉资源。

## 不应存放的内容

- 共享品牌资源、应用资源包、临时导出或未授权媒体。
