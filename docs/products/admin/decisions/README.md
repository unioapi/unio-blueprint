# Admin（管理后台）领域决策

## 目的

记录影响范围完全位于管理后台领域内的长期选择。

## 范围

管理后台产品架构、信息架构、运营流程和领域内部技术约束。

## 职责

- 保存决策背景、备选方案与影响。
- 链接受影响的页面设计、质量目标和路线图事项。
- 将跨领域选择提升为全局决策。

## 适合存放的内容

- 管理后台领域已提议、接受、取代或拒绝的 ADR。
- 不会对其他产品领域施加规则的决策。

## 不应存放的内容

- 平台级选择、临时笔记或实现任务。
- 由其他产品领域负责的决策。
