# SDK（软件开发工具包）

## 目的

集中维护官方 SDK 的产品方向、开发者体验、质量要求、路线图和领域决策。

## 范围

官方开发者类库、公共使用体验、支持的集成模式、兼容性要求和领域专用资源。

## 职责

- 定义 SDK 的使用者、目标和边界。
- 维护各语言类库共享行为和开发者体验的权威说明。
- 记录只影响 SDK 的决策和质量目标。
- 与 Gateway 和共享 API 规范保持公共契约一致。

## 适合存放的内容

- SDK 概览、路线图、词汇表和质量目标。
- 跨语言 SDK 功能与体验设计。
- 仅由 SDK 使用的决策、图示和资源。

## 不应存放的内容

- 单一语言包的源码、生成参考、安装命令或发布流程。
- Gateway 契约权威内容或 Documentation Site 信息架构。
- 平台共享规范。
