# Console（用户控制台）图示

## 目的

存放仅由用户控制台文档使用的图示源文件和可读版本。

## 范围

用户旅程、信息关系、页面流程和领域架构图。

## 职责

- 同时保留可编辑源文件和可读版本。
- 每张图都必须由说明性 Markdown 文档引用。
- 提供无障碍文字说明和明确负责人。

## 适合存放的内容

- 用户控制台专用 Mermaid、Excalidraw 或图片图示。

## 不应存放的内容

- 共享平台图、没有说明的导出文件或应用生成内容。
