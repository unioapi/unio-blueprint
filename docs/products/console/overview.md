# Console（用户控制台）概览

## 目的

从产品角度定义用户控制台，不依赖当前技术实现。

## 需要回答的问题

- 哪些客户和角色使用用户控制台，他们需要什么？
- 用户控制台负责哪些管理目标与旅程？
- 它与 Admin、Documentation Site 和 Gateway 的边界在哪里？
- 哪些能力和指标代表用户控制台成功？
- 哪些平台规范与外部依赖会约束用户控制台？

## 必备章节

1. 产品陈述
2. 受众与任务
3. 自有能力与非目标
4. 主要用户旅程
5. 依赖与约束
6. 成功指标

## 当前状态

本占位文档不代表已经批准的产品行为。
