# Console（用户控制台）

## 目的

集中维护用户控制台的产品方向、体验设计、质量要求、路线图和领域决策。

## 范围

面向客户的管理体验，包括工作流、页面、信息架构和领域专用资源。

## 职责

- 定义用户控制台的受众、目标和边界。
- 维护面向客户的工作流和页面设计权威说明。
- 记录只影响用户控制台的决策和质量目标。
- 通过链接遵循平台共享规范。

## 适合存放的内容

- 用户控制台概览、路线图、词汇表和质量目标。
- 用户控制台页面与用户旅程设计。
- 仅由用户控制台使用的决策、图示和资源。

## 不应存放的内容

- 由 Admin 负责的内部运营流程。
- 共享界面规范或平台架构。
- 源代码、框架配置、部署步骤或生成数据。
