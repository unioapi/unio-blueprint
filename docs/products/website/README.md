# Website（官网）

## 目的

集中维护官网的产品方向、体验设计、质量要求、路线图和领域决策。

## 范围

面向公众的官网定位、信息架构、页面要求、内容体验和领域专用资源。

## 职责

- 定义官网受众、目标和边界。
- 维护官网页面与内容设计的权威说明。
- 记录只影响官网的决策和质量目标。
- 通过链接遵循平台共享规范。

## 适合存放的内容

- 官网概览、路线图、词汇表和质量目标。
- 官网页面与用户旅程设计。
- 仅由官网使用的决策、图示和资源。

## 不应存放的内容

- 由 Documentation Site 负责的开发者文档。
- 共享设计规范或平台架构。
- 源代码、框架配置、部署步骤或分析数据导出。
