# Website（官网）概览

## 文档状态

本文只记录当前暂定的官网一级入口及其所有权边界。页面内容、导航顺序、路由、
视觉设计和交付时间尚未确认，因此本文保持 `draft`。

## 目的

从产品角度定义官网自有页面及其连接其他产品领域的公开入口，不依赖当前技术实现。

## 当前确认的一级入口

| 入口 | 作用 | 所有权 | 当前结论 |
| --- | --- | --- | --- |
| Home（首页） | 官网公共入口 | Website（官网） | 保留；具体内容后续讨论 |
| Pricing（定价） | 承载商业定价信息 | Website（官网） | 暂时保留；订阅套餐确定后再完善 |
| Docs（文档） | 引导开发者进入公开集成文档 | [Documentation Site（文档站）](../docs-site/README.md) | 作为跨产品入口，不在官网复制文档内容 |
| Console（用户控制台） | 引导客户进入账户与使用管理产品 | [Console（用户控制台）](../console/README.md) | 作为跨产品入口，不在官网复制控制台能力 |

这四项构成当前已经确认的最小入口集合，不代表完整网站地图，也不表示对应产品已经
交付。

## 所有权边界

- Website（官网）负责 Home（首页）和 Pricing（定价）的页面目标与内容设计。
- Docs（文档）可以出现在官网导航中，但内容与体验由 Documentation Site（文档站）负责。
- Console（用户控制台）可以出现在官网导航中，但账户管理与客户自助体验由 Console 负责。
- 本文确认入口名称与领域关系，不确认 URL、子域名、导航位置或跳转行为。

## 待讨论内容

- Home（首页）的受众、页面目标、信息层级、文案和主要行动。
- Pricing（定价）在订阅套餐推出前应展示的最小信息。
- 四个入口的导航顺序、标签、URL 和跨产品跳转方式。
- 是否增加其他一级入口或页脚支持入口。
- 官网的质量要求、成功指标和交付顺序。

页面内容确认后，使用[页面设计模板](../../templates/page-design.md)在
[页面设计目录](pages/README.md)中建立对应的权威文档。
