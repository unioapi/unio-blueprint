# Documentation Site（文档站）

## 目的

集中维护文档站的产品方向、体验设计、质量要求、路线图和领域决策。

## 范围

面向开发者发布的文档体验，包括信息架构、页面要求、内容交付、搜索和领域资源。

## 职责

- 定义文档站受众、目标和边界。
- 维护页面、导航、内容发现和发布体验的权威说明。
- 记录只影响文档站的决策和质量目标。
- 通过链接遵循平台共享规范。

## 适合存放的内容

- 文档站概览、路线图、词汇表和质量目标。
- 文档站页面、用户旅程和内容交付设计。
- 仅由文档站使用的决策、图示和资源。

## 不应存放的内容

- 本蓝图内部知识架构。
- 官网定位或平台共享规范。
- 生成的参考文档、源代码、框架配置或部署步骤。
