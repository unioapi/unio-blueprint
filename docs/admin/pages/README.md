# Admin（管理后台）页面设计

## 目的

定义管理后台页面和跨页面操作旅程的目标、数据、状态、控制措施与交互。

## 范围

管理后台自有页面设计、与具体路由无关的旅程、数据要求和验收标准。

## 职责

- 为每个页面或旅程建立唯一权威设计。
- 将共享模式链接到平台规范。
- 覆盖权限、审计、加载、空状态和错误状态。

## 适合存放的内容

- 使用[页面设计模板](../../templates/page-design.md)创建的管理后台页面设计。
- 管理后台旅程图和页面级运营规则。

## 不应存放的内容

- 组件源码、框架路由、共享 UI 规范或其他产品领域负责的页面。
