# Admin（管理后台）

## 目的

集中维护管理后台的产品方向、体验设计、质量要求、路线图和领域决策。

## 范围

面向内部运营人员的管理体验，包括工作流、页面、信息架构和领域专用资源。

## 职责

- 定义管理后台操作人员、目标和边界。
- 维护内部运营流程和页面设计的权威说明。
- 记录只影响管理后台的决策和质量目标。
- 通过链接遵循平台共享规范。

## 适合存放的内容

- 管理后台概览、路线图、词汇表和质量目标。
- 管理后台页面与操作人员旅程设计。
- 仅由管理后台使用的决策、图示和资源。

## 不应存放的内容

- 由 Console 负责的客户管理流程。
- 共享界面规范或平台架构。
- 源代码、框架配置、部署步骤或运营数据导出。
