# 平台架构总览

## 目的

用最短但完整的方式说明 UnioAPI 平台边界，以及各主要产品领域的职责。

## 需要回答的问题

- 哪些用户和业务目标决定了平台边界？
- 哪些能力属于平台公共能力，哪些由具体领域负责？
- 各产品领域如何协作，同时避免所有权重叠？
- 哪些外部系统和信任边界会实质影响平台？

## 必备视图

- 不依赖实现仓库也能理解的简明叙述。
- 由[平台上下文](context.md)维护的上下文图。
- 链接到各产品概览的职责地图。
- 支撑非显然选择的已接受决策链接。

## 边界

不得包含服务名、源码树、接口清单、数据库表结构或部署命令。

## 完成条件

当文档已有明确负责人、完成评审的图示，并链接到各领域权威文档后，方可替换
本占位并调整状态。
