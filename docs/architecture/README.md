# 平台架构

## 目的

解释 UnioAPI 为何存在、哪些长期约束影响平台，以及平台应当如何演进。

## 范围

平台愿景、原则、上下文、演进策略、概念部署、共享术语、质量属性和重大风险。

## 职责

- 建立能够指导所有产品领域的稳定设计依据。
- 描述系统边界，但不绑定具体仓库结构。
- 将架构结论与已接受的全局决策关联起来。
- 公开假设、取舍和尚未解决的风险。

## 适合存放的内容

- 长期有效的平台设计依据与约束。
- 产品、参与者和外部系统之间的概念关系。
- 跨产品质量属性与架构风险。

## 不应存放的内容

- 源码结构、函数名、框架配置或操作手册。
- 只属于单一产品领域的页面行为。
- 具体建设规则；这类内容属于[平台规范](../specifications/README.md)。
