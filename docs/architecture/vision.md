# 平台愿景

## 目的

定义 UnioAPI 平台希望为客户、开发者和组织创造的长期价值。

## 需要回答的问题

- 平台服务于哪些人？
- 哪些问题重要到需要由平台承担？
- 产品和实现变化时，哪些目标必须长期保持不变？
- 哪些相邻问题明确不在平台范围内？
- 组织如何判断平台取得了有意义的进展？

## 预期结构

1. 问题陈述
2. 目标人群与需求
3. 期望的未来状态
4. 平台边界与非目标
5. 长期成功衡量方式
