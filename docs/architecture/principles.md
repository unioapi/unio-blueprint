# 架构原则

## 目的

定义一组少而稳定的原则，用于解决架构方案之间的取舍。

## 原则格式

每条原则必须说明：

1. 简短明确的要求；
2. 适用场景；
3. 背后的原因；
4. 预期影响与取舍；
5. 展示该原则如何应用的决策链接。

## 收录条件

只有同时满足以下条件的原则才属于这里：适用于整个平台、能够跨实现长期有效、
可以帮助解决方案冲突，并已获得架构负责人批准。

## 边界

编码约定和组件规则属于[平台规范](../specifications/README.md)；一次性选择属于
[架构决策记录](../decisions/README.md)。
