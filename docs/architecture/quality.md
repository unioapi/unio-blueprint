# 平台质量属性

## 目的

定义约束所有产品领域的质量特征，并使不同目标之间的取舍可以衡量。

## 属性格式

| 字段 | 要求 |
| --- | --- |
| 属性 | 使用本文或平台词汇表中已经定义的术语。 |
| 场景 | 描述触发条件、运行状态和期望响应。 |
| 指标 | 给出可观察目标和测量方法。 |
| 优先级 | 说明它相对其他质量属性的优先级。 |
| 负责人 | 指定负责复审的角色。 |
| 证据 | 链接测试、报告或运行证据，不复制内容。 |

## 待评估方向

必须评估可用性、兼容性、可观测性、性能、隐私、可靠性、安全性、可维护性和
易用性。列在这里不代表具体目标已经确定。

## 边界

领域专用目标写入各领域的 `quality.md`，并引用其细化的平台质量属性。
