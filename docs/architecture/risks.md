# 平台架构风险

## 目的

跟踪可能影响多个产品领域、且结果存在不确定性的风险。

## 风险登记表

| 编号 | 风险 | 证据 | 影响 | 可能性 | 缓解措施 | 负责人 | 复审日期 | 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 待分配 | 暂未登记平台级风险。 |  |  |  |  |  |  | open |

## 维护规则

- 分开记录证据与假设。
- 每项风险必须有一名责任人和复审触发条件。
- 缓解工作应链接到路线图或已接受决策。
- 只影响单一领域的风险应移到该领域的质量或路线图文档。
- 风险关闭时记录日期和结果，不删除历史条目。
