## 维护规则

- 分开记录证据与假设。
- 每项风险必须有一名责任人和复审触发条件。
- 缓解工作应链接到路线图或已接受决策。
- 只影响单一领域的风险应移到该领域的质量或路线图文档。
- 风险关闭时记录日期和结果，不删除历史条目。
- 风险的可能性、影响、负责人和复审日期必须在平台负责人评审后补齐；在此之前不得用
  Gateway 的单产品优先级代替平台定级。
