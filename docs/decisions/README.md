# 全局架构决策

## 目的

长期保存影响多个 UnioAPI 产品领域的重要选择，包括背景、备选方案、依据和影响。

## 范围

跨平台架构、技术、兼容性、数据、安全和组织边界决策。

## 职责

- 为每项重要全局选择建立持久记录。
- 保证已接受决策的原意不可改写。
- 链接取代关系和受影响规范。
- 明确列出影响与后续工作。

## 适合存放的内容

- 对多个产品领域产生影响的决策。
- 会约束未来平台工作的选择。
- 用于取代旧全局决策的新记录。

## 不应存放的内容

- 影响完全位于单一产品领域的选择。
- 临时实现笔记或会议纪要。
- 尚未形成具体选择的模糊提案。

## 记录规则

1. 复制 [ADR 模板](../templates/adr.md)。
2. 使用下一个可用编号，文件名格式为 `NNNN-descriptive-decision.md`。
3. 初始状态设为 `proposed`。
4. 由架构负责人和受影响领域负责人共同评审。
5. 若要改变已接受决策，必须新建 ADR 并标记取代关系，不得改写原结论。
