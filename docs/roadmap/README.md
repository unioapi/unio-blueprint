# Roadmap（平台路线图）

## 目的

协调需要多个 UnioAPI 产品领域共同完成的目标与依赖。

## 范围

跨产品目标、推进顺序、依赖关系、规划假设和复审节奏。各领域路线图在自身范围内
细化平台方向。

## 职责

- 表达预期结果，而不是堆积任务清单。
- 展示跨领域依赖和决策门槛。
- 区分已经承诺的事项、可选方向和探索工作。
- 将计划链接到平台策略、风险和领域路线图。

## 适合存放的内容

- 需要多个领域协作的事项。
- 平台里程碑和可衡量的结果假设。
- 可能改变推进顺序的假设或决策。

## 不应存放的内容

- 工程工单、迭代计划或发布清单。
- 单一领域的待办事项。
- 没有负责人和预期结果的无时间愿望清单。
