# 蓝图维护脚本

## 目的

提供轻量、无第三方依赖的检查，持续保证蓝图结构一致。

## 范围

面向整个仓库的文档架构与写作规则校验。

## 职责

- 输出可以直接定位到文件的错误。
- 保证在本地和持续集成环境中安全运行。
- 只实现蓝图权威文档中已经确定的规则。

## 适合存放的内容

- 本仓库专用、结果确定的校验与维护工具。

## 不应存放的内容

- 产品实现、部署自动化、生成内容，或其他仓库负责的工具。

## 命令

| 命令 | 用途 |
| --- | --- |
| `make validate` | 校验目录结构、元数据、命名和本地链接 |
